# Archived scripts

These files preserve the Kontxt demos and GitHub OIDC E2E script from Orka before the provider integration moved to this repository. They are historical migration material and are not runnable against current Orka.

They reference removed `kontxt` profile/TTS URL settings, in-tree build helpers, and demo libraries that are absent here. `demo/install-kontxt.sh` also retains its original repository-relative paths.

Use [scripts/kind-ci.sh](../scripts/kind-ci.sh) through the [current quickstart](../README.md#run-the-smoke-test). See the [migration table](../docs/legacy-quickstart.md) when adapting an older installation.
